Takomi Tool-Call UI Design Directions

Archived visual exploration; the implemented Takomi-Code UI follows the hybrid direction

Strengths and Tradeoffs Summary Matrix

Metric Direction A: Inline Chronological Log Direction B: Grouped Block Cards Direction C: Split-Pane Inspector Direction D: Hybrid Pinned Inspector (A + C)
Visual Footprint Compact by default, but stacks vertically in the thread as tools run. Medium-large. Groups related steps into a single unified card in the thread. Extremely compact in chat stream. Details are loaded in the secondary pane. Optimal balance. Inline logs collapse and are fully canonical. Right inspector is redundant/optional (can be closed to expand chat width). Inline is canonical; inspector is optional.
Disclosure Paradigm Accordion disclosures inline inside the chronological thread. Accordion sub-sections inside the card block boundaries. Click timeline row to load/focus that tool's state in the inspector pane. Full Direction A rich inline accordions (canonical) + optional synchronized inspector workspace panel on the right.
Strengths & Pros Chronological Context Low Integration Cost

Preserves strict temporal order relative to surrounding chat answers.

 High Scannability Context Isolation

Binds subagent pools, policies, and board progress into a unified visual component.

Zero Chat Bloat Deep Inspect Panel

Keeps the chat flow highly readable. Perfect for review tasks and displaying large diffs.

Canonical Inline Detail Optional Closeable Inspector Updates In-Place

Maintains complete operational context in inline accordion. Inspector is a closeable synchronized convenience panel with sticky Board/Subagent state.

Weaknesses & Cons High Thread Noise

Intense parallel tasks generate a huge wall of logs, pushing chat off-screen.

 Stream Interruption

Breaks the linear stream metaphor. Updating older cards changes visual state out of order.

Context Splitting High Click Cost

Forces the eye to jump between left and right panes to read any tool outputs.

 Redundant View Screen Space

Duplicate states in both timelines and right inspector when open, requiring wide screens.
